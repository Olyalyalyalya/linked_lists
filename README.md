# Лабораторная работа 4. Связные списки

Дисциплина «Алгоритмизация и программирование», МГТУ им. Н.Э. Баумана.
Выполнила: Жохова О. С., группа ИУ5-13.

Реализованы однонаправленный список с указателем bottom, двунаправленный
список с ограничителями, многопотоковый список планет и алгоритм черепахи
и кролика для поиска цикла.

## Сборка и запуск

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel $(nproc)
./build/linked_lists
```

Программа выводит меню. Нужно ввести номер задания (1-11), 0 - выход.
В задании 10 открывается своё меню выбора сортировки планет.

Тесты:

```bash
cd build && ctest
```

Проверка утечек памяти:

```bash
valgrind --leak-check=full --error-exitcode=1 ./build/tests/list_tests --gtest_brief=1
```

## Обработка ошибок

Используются исключения `std::invalid_argument`: nullptr вместо ячейки,
поиск максимума в пустом списке, удаление ограничителя, вставка после
нижнего ограничителя, неверный номер ячейки в `make_cycle`, неверные данные
планеты. Неверный ввод в меню (буквы, число вне диапазона) не считается
ошибкой: программа пишет сообщение и просит ввести номер ещё раз.

## Задания и функции

| Задание | Что сделано | Функции |
|---|---|---|
| 1 | список с bottom: добавление в конец за O(1), удаление | `add_at_end`, `add_at_beginning`, `delete_value` |
| 2 | наибольший элемент несортированного списка | `find_max` |
| 3 | добавление в начало двунаправленного списка | `add_at_beginning(DoublyList&, DCell*)` |
| 4 | добавление в конец двунаправленного списка | `add_at_end(DoublyList&, DCell*)` |
| 5 | задания 3 и 4 через InsertCell | `insert_cell`, `add_at_beginning_via_insert`, `add_at_end_via_insert` |
| 6 | удаление ячейки из двунаправленного списка | `delete_cell` |
| 7 | поиск с верхнего и с нижнего ограничителя | `find_sorted_from_top`, `find_sorted_from_bottom` |
| 8 | вставка в сортированный список с ограничителями min и max | `insert_sorted` |
| 9 | проверка, отсортирован ли список | `is_sorted` |
| 10 | многопотоковый список планет | `add_planet_to_list`, `print_planets` |
| 11 | черепаха и кролик | `has_cycle`, `find_cycle_start`, `break_cycle` |

## Проверяемые сценарии (37 тестов Google Test)

- обычные случаи: добавление и удаление в начале, середине и конце,
  максимум, сортировка планет по трём потокам, поиск начала цикла;
- граничные случаи: пустой список, одна ячейка, удаление единственной
  ячейки (top и bottom становятся nullptr), значения INT_MIN и INT_MAX
  при вставке в сортированный список, цикл из одной ячейки, весь список
  как цикл;
- некорректные данные: nullptr вместо ячейки, удаление ограничителя,
  вставка после нижнего ограничителя, неверный номер в `make_cycle`,
  пустое имя и отрицательная масса планеты.
